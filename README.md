# Contacts Manager App

A React application for managing private contacts.

## Live Demo

[View demo](https://goit-react-hw-07-two-navy.vercel.app)

## Features

- Add and delete contacts
- Filter contacts by name
- Manage app state with Redux Toolkit
- Form handling with Formik
- Client-side routing with React Router

## Tech Stack

- React
- Redux Toolkit
- Axios
- Formik
- React Router
- CSS Modules
- Vite

## Purpose

This project was created to practice React state management, routing, form handling and API interaction.
